# 04 Launch checklist

Tick everything before you send the link to anyone outside your circle.

## Content
- [ ] No lorem ipsum, "Brand", "Feature title" or "Replace with <img>" left
- [ ] Every page has one clear action (button or form)
- [ ] Spelling checked, numbers and prices correct
- [ ] Contact details are real

## Structure and accessibility
- [ ] One `<h1>` per page; headings go h1, h2, h3 without skipping
- [ ] Every image has meaningful `alt` text (or `alt=""` if decorative)
- [ ] Every input has a `<label>`
- [ ] You can use the whole page with only the Tab key and see where focus is
- [ ] Text is readable in light and dark mode (check muted gray text especially)

## Responsive
- [ ] Looks right at 360px wide (small phone)
- [ ] Looks right at 768px (tablet) and 1280px (desktop)
- [ ] Nothing scrolls sideways

## Links and forms
- [ ] No `href="#"` left (search your files for `href="#"`)
- [ ] Every link and button goes somewhere or does something
- [ ] Forms submit and show success and error messages
- [ ] A 404 page exists (layouts section of html-reference.html)

## Page info
- [ ] `<title>` and meta description written for every page
- [ ] Favicon added
- [ ] Share image set (og:image)

## Performance
- [ ] Images compressed (aim under 200 KB each)
- [ ] No unused files in the repo

## Deploy
- [ ] Live on https
- [ ] Opened the live URL on your phone, not just your computer
- [ ] Privacy page linked if you collect emails
- [ ] Last commit pushed to GitHub

## After launch
- [ ] Sent the link to 3 people and asked: "What did you expect to happen?" and "What confused you?"
- [ ] Chose ONE change and shipped it
