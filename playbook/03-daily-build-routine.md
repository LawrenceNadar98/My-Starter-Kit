# 03 Daily build routine (1 to 2 hours)

| Time | What | Rule |
|---|---|---|
| 5 min | Open NOTES.md. Read the MUST list. Write today's ONE goal. | One goal only. It must be finishable today. |
| 60 to 90 min | Build. Paste blocks from html-reference.html and replace the text. | No browsing for new ideas, tutorials or inspiration. |
| 10 min | Open the page at phone width and at desktop width. Fix anything broken. Then `git add .`, `git commit -m "what you did"`, `git push`. | Push every day, even if it is ugly. |
| 5 min | Write tomorrow's first task in NOTES.md. | So tomorrow you start without thinking. |

## If you are stuck
- 15 minutes stuck: re-read the recipe and the component you pasted.
- 30 minutes stuck: shrink the task to something you can finish in 15 minutes, or ask for help with the exact error plus the code.
- A new idea shows up: write it under IDEAS in NOTES.md. Do not open it again until the product is live.

## Weekly (10 minutes, same day each week)
- Is the MUST list still 3 items or fewer?
- What is live? Send the link to one person.
- What is the one change for next week?
